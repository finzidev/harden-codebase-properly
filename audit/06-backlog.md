# 06 — Backlog: what changes, what ships, what waits

Corpus at `c32367a`: 28 Markdown files, 28,768 words (`find . -name '*.md' -not -path './.git/*' -print0 | xargs -0 wc -w`). Growth budget: **+15 % = 33,083 words maximum** for the files a mode can load (`SKILL.md`, `README.md`, `procedure.md`, `GLOSSARY.md`, `modes/`, `areas/`, `briefs/`, `templates/`, plus any new `examples/` or `sql/`). `audit/`, `docs/decisions/` and `CHANGELOG.md` are outside every load list and outside the count (decision 005).

Severity: **P1** = the skill instructs something false, unsafe or unexecutable · **P2** = a real gap or ambiguity a cold agent will hit · **P3** = polish. Effort: S ≤ 10 lines · M a section or a small new file · L new tooling. Source ids: `01` = `01-integrity.md` (its findings are numbered by check, e.g. `01 A6-02`), `02` = `02-usability.md`, `03a/b/c` = evidence slices, `04` = `04-coverage.md`, `05` = `05-failure-modes.md`.

Ordering rule: **defects prevented per token added**. For a skill every added line is paid on every future run, so deletions and compressions are first-class rows (§ X). Rows are grouped by what they buy the reader — **more correct** (C, E), **easier to use** (U), **covers more** (V) — so the PR reviewer can choose between them.

Ship column: **W3** = applied in wave 3 · **spec** = specification committed under `audit/specs/`, not applied · **issue** = to be opened on the repo · **no** = rejected, reason in the row.
