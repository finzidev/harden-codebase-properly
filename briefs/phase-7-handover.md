# Phase 7 Brief: Handover

Common header: as in `phase-1-gates.md`, plus: **no credentials in reports**; every action on the new environment is "ask first." Reference: `areas/data-security.md`, `areas/method-documentation.md`.

Order: `R7.1` first; `R7.2` after the go-ahead; `R7.3`, `R7.4`, `R7.5` in sequence on the new environment; `R7.6` at the end.

---

### R7.1 Handover plan in stages
`model: sonnet` · files: `docs/handover/HANDOVER-PLAN.md`
CONTEXT: what the client must provide: <account, domain, card, verification email>; what they don't: <everything else>.
GOAL: three stages: (1) before the meeting, everything that does not require the client; (2) in the meeting, only what only they can do, with the exact steps and timing; (3) afterward, verification and minutes. Secrets generated by the consultant and revocable; never asked of the client; database empty or seeded only with what was approved.
DONE: plan with a checklist per stage.

### R7.2 New environment (after the go-ahead)
`model: sonnet` · ONLY the approved steps
GOAL: accounts owned by the client; new database project; environment variables set with regenerated secrets; test endpoints disabled; the way back to the old environment if the new one fails, written before the switch.
DON'T: copy secrets from the old environment; report values back.
DONE: table variable | set? (yes/no, never the value).

### R7.3 Migration replay and table verification
`model: sonnet`
GOAL: all migrations applied on the new project; table, function and policy counts equal to expected; the permissions verification query (Phase 2) comes back clean.
DONE: table expected | found, for tables, functions, policies, grants.

### R7.4 Backup and restore on the new environment
`model: sonnet`
GOAL: one backup run seen arriving (the last link's run log line); a restore onto a scratch project with matching table-by-table counts.
DONE: dates and counts.

### R7.5 Channels on the new environment
`model: sonnet`
GOAL: every channel (email, alerts, sync) tested with an injected failure on the new environment, seen arriving.
DONE: table channel | arrived | date.

### R7.6 Minutes
`model: sonnet` · files: `docs/handover/MINUTES-<date>.md`
GOAL: a record (never updated afterward): what was delivered, what was verified and with which command, remaining open questions with their record, who owns what as of today; an SBOM generated by command, delivered with the minutes; every P1 with status `parked` by id, with its Ruling line verbatim and cost-if-wrong, signed as a separate item.
DONE: minutes written; no team credential survives (declared, with the verification performed).
